# 사진 넣는 곳

이 폴더에 사진을 넣으면 **코드 수정 없이** 일러스트가 사진으로 바뀝니다.
파일이 없는 자리는 SVG 일러스트가 대신 그려지므로, 한 장씩 채워도 화면이 깨지지 않습니다.

## 규칙

- 파일명은 아래 표의 **키와 정확히 일치**해야 합니다 (확장자는 자유)
- 지원 확장자: `.jpg` `.jpeg` `.png` `.webp` `.avif`
- 같은 키로 여러 확장자가 있으면 알파벳 순으로 먼저 오는 파일을 씁니다
- 개발 서버가 떠 있었다면 **재시작**해야 반영됩니다 (폴더는 프로세스당 한 번만 읽습니다)

## 필요한 사진 12장

| 파일명 | 비율 | 어떤 장면 |
| --- | --- | --- |
| `hero` | 16:10 | 청소를 마친 밝은 거실. 창으로 빛이 드는 넓은 실내 |
| `move-in` | 4:3 | 입주청소 — 가구 없는 빈집, 창틀·바닥 |
| `move-out` | 4:3 | 이사청소 — 이삿짐 박스, 비워진 방 |
| `stairs` | 4:3 | 계단청소 — 공동주택 계단·복도 |
| `office` | 4:3 | 사무실청소 — 책상이 늘어선 업무 공간 |
| `commercial` | 4:3 | 상가·매장청소 — 카페나 식당 홀 |
| `construction` | 4:3 | 준공청소 — 인테리어 직후 현장, 사다리·자재 |
| `home-regular` | 4:3 | 가정 정기청소 — 생활감 있는 거실 |
| `special` | 4:3 | 특수청소 — 전문 장비, 보호구 |
| `before` | 4:3 | **청소 전** — 아래 `after` 와 **같은 구도** |
| `after` | 4:3 | **청소 후** — 위 `before` 와 **같은 구도** |

`before` / `after` 는 랜딩의 비교 슬라이더에 쓰입니다. **구도가 같아야** 효과가 납니다.

## 권장 사양

- 가로 1600px 내외, 500KB 이하 (`.webp` 권장)
- 사람 얼굴이 크게 나오면 초상권 확인 필요
- Pixabay·Pexels 등 상업적 사용이 허용된 출처만 사용

## 확인

사진을 넣고 서버를 재시작한 뒤 해당 화면을 열면 됩니다.
일러스트가 그대로 보인다면 파일명이 표와 다른 것입니다.
