# 이미지 넣는 곳

이 폴더에 이미지를 넣으면 **코드 수정 없이** 일러스트가 사진으로 바뀝니다.
파일이 없는 자리는 SVG 일러스트가 대신 그려지므로, 한 장씩 채워도 화면이 깨지지 않습니다.

## 가장 빠른 방법 — 한 번에 생성

```bash
OPENAI_API_KEY=sk-... npm run images
```

6장이 생성돼 올바른 파일명으로 이 폴더에 저장됩니다.

```bash
npm run images -- --dry-run          # 호출 없이 계획만 확인
npm run images -- hero after before  # 특정 키만
npm run images -- --force            # 이미 있어도 다시 생성
```

- 모델명이 맞지 않아 실패하면 `OPENAI_IMAGE_MODEL=dall-e-3` 처럼 바꿔 다시 실행하세요.
  오류 메시지에 원인이 그대로 찍힙니다.
- `npm i -D sharp` 를 해두면 webp 로 줄여 저장합니다. 없으면 원본 PNG 라 용량이 큽니다.

ChatGPT 웹에 직접 붙여넣고 싶으면 **[PROMPTS.md](./PROMPTS.md)** 를 보세요.

## 직접 넣을 때 규칙

- 파일명은 아래 표의 **키와 정확히 일치**해야 합니다 (확장자는 자유)
- 지원 확장자: `.jpg` `.jpeg` `.png` `.webp` `.avif`
- 같은 키로 여러 확장자가 있으면 알파벳 순으로 먼저 오는 파일을 씁니다
- 개발 서버가 떠 있었다면 **재시작**해야 반영됩니다 (폴더는 프로세스당 한 번만 읽습니다)

## 필요한 이미지 6장

| 파일명 | 비율 | 어떤 장면 |
| --- | --- | --- |
| `hero` | 3:2 | 청소를 마친 밝은 거실. 창으로 빛이 드는 실내 |
| `move-in` | 1:1 | 입주청소 — 가구 없는 빈집, 창틀·바닥 |
| `stairs` | 1:1 | 계단청소 — 공동주택 계단·복도 |
| `office` | 1:1 | 사무실청소 — 책상이 늘어선 업무 공간 |
| `after` | 3:2 | **청소 후** — 아래 `before` 와 **같은 구도** |
| `before` | 3:2 | **청소 전** — 위 `after` 와 **같은 구도** |

`before` / `after` 는 랜딩의 비교 슬라이더에 쓰입니다. **구도가 같아야** 효과가 납니다.

## "예시 이미지" 표기

`generated.json` 에 적힌 키에는 화면에 **예시 이미지** 배지가 붙습니다.
AI로 만든 이미지를 실제 시공 결과처럼 보이게 두면 고객을 오도하기 때문입니다.

```json
["after", "before", "hero"]
```

`npm run images` 가 이 파일을 자동으로 관리합니다.
**실제 시공 사진으로 교체했다면 그 키를 목록에서 지우세요.** 배지가 사라집니다.

## 권장 사양

- 가로 1600px 내외, 500KB 이하 (`.webp` 권장)
- 사람 얼굴이 크게 나오면 초상권 확인 필요
- 직접 구한 사진은 상업적 사용이 허용된 출처만 사용
